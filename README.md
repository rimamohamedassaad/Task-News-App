# News Mobile App
A React Native application that fetches real-time news using the GNews API.

## Features
- Fetch N number of articles.
- Search by keywords.
- Filter by Title/Author.

## Setup Instructions
1. Clone the repo: `git clone https://github.com/rimamohamedassaad/Task-News-App.git`
2. Install dependencies: `npm install`
3. Get an API key from [GNews.io](https://gnews.io/)
4. Create a `.env` file or replace the `API_KEY` constant in `newsService.ts`.
5. Run the app: `npx expo start`
6. Press W and see the result on web , or use expo go app 

## Technologies Used
- React Native (Expo)
- TypeScript
- GNews API
